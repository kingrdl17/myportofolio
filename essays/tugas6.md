### Tugas 6
1. REST adalah gaya arsitektur yang mendefinisikan cara resource diidentifikasi via URL unik dan dimanipulasi menggunakan HTTP methods secara stateless. JSON hanya format data. API bisa mengembalikan JSON tapi tetap bukan RESTful jika urlnya menggunakan pola aksi (misal /add-education/) bukan resource (/api/educations/), atau tidak memanfaatkan HTTP methods dengan benar. PUT mengganti seluruh resource, dan PATCH mengupdate beberapa field saja.
2. Serializer mengconvert objek model Django ke JSON (serialization) dan sebaliknya (deserialization) lengkap dengan validasi otomatis per field, sanitasi data, dan error terstruktur. Dibanding JsonResponse manual, serializer jauh lebih aman, deklaratif, dan tidak perlu menulis logika validasi dari nol
3. Autentikasi memverifikasi siapa user nya, otorisasi menentukan apa yang boleh dilakukan seorang user. Menyembunyikan tombol di frontend saja tidak cukup karena permintaan bisa dikirim langsung via cURL, Postman, atau browser console yang melewati UI sepenuhnya. Validasi di server wajib ada sebagai lapisan keamanan nyata.
4. SessionAuthentication mengandalkan session cookie yang otomatis dikirim browser, sehingga rentan serangan CSRF dari situs berbahaya. Token CSRF memastikan request benar-benar berasal dari halaman yang valid. force_authenticate menyuntikkan user langsung ke objek request, melewati seluruh pipeline middleware autentikasi dan CSRF, sehingga tidak mencerminkan kondisi nyata. Untuk membuktikan proteksi CSRF berjalan, harus menggunakan APIClient(enforce_csrf_checks=True) dengan .login().
