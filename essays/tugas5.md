### Tugas 5

1. Debouncing adalah menunggu selama beberapa jeda waktu setelah tidak ada action dari user. Debouncing berlaku seperti rate-limiter yang pada pencarian AJAX, bisa mengurangi beban server karena terjadinya request spam.
2. await berfungsi untuk mengpause eksekusi line kode berikutnya sampai Promise tersebut selesai diproses. Jika await tidak digunakan maka akan menyebabkan masalah seperti runtime error
3. XSS adalah jenis serangan dimana seseorang bisa 'inject' sebuah script ke dalam website seperti melalui sebuah form field. AJAX/Javascript lebih rentan karena tidak mempunyai sanitasi bawaan, sedangkan django punya. Jadi perlu step tambahan untuk antisipasi
